# Quy ước làm việc nhóm (Team Rules)

1. **Quy tắc nhánh (Branching):**
   - Tuyệt đối không commit hoặc push trực tiếp lên nhánh `main`.
   - Mỗi tính năng/tài liệu tạo nhánh riêng: `feature/<ten-chuc-nang>` hoặc `docs/<ten-tai-lieu>`.

2. **Quy tắc Commit:**
   - Thông điệp commit phải rõ ràng: `feat: them chuc nang X` hoặc `docs: cap nhat tai lieu Y`.

3. **Quy tắc Pull Request (PR):**
   - Mọi thay đổi đều phải mở PR vào `main`.
   - Cần ít nhất 1 thành viên review và duyệt trước khi merge.
