# Hotel Booking System

## Hướng dẫn cài đặt và khởi chạy

1. Clone dự án:
```bash
git clone https://github.com/HuyUKid/hotel-booking-system.git
cd hotel-booking-system
```

2. Cài đặt thư viện:
```bash
pip install -r requirements.txt
```

3. Khởi chạy máy chủ:
```bash
python manage.py runserver
```
